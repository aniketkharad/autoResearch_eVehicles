# Dataset Directory

This directory contains the datasets and deterministic cross-validation splits used across the project.

## Files

| File | Shape / Size | Description |
| :--- | :--- | :--- |
| `train.csv` | 668,665 rows x 15 cols (~44.7 MB) | Primary training dataset containing demographic, vehicle, and commute features with target `Will_Buy_EV`. |
| `test.csv` | 286,571 rows x 14 cols (~18.3 MB) | Test evaluation set with `id` column. Strictly isolated from the autonomous research loop. |
| `splits.npy` | 668,665 entries (~668 KB) | Invariant Stratified 5-Fold cross-validation split assignments (`seed=101`), generated by `prepare.py`. |
| `EV_Adoption_and_Range_Anxiety_Dataset.csv` | 10,000 rows (~692 KB) | Original empirical reference dataset used for exploratory domain calibration. |

## Target Variable
* `Will_Buy_EV`: Binary target (1 = Yes, 0 = No) with ~17.46% positive class balance.
